1. Demo scope

PayPulse demonstrates PayPal Sandbox invoice, order, subscription, collection, dispute, and webhook flows. Do not use the demo to process real customer payments, real refunds, or real disputes.

2. Accounts and credentials

PayPal credentials and model credentials are stored on the server in environment variables. They are not sent to the browser. You are responsible for protecting those credentials and for restricting access to any shared deployment.

3. AI features

Model output can be incomplete, incorrect, or unexpected. The application keeps a deterministic fallback, but every generated action should be reviewed before it is used. Do not rely on model output for legal, tax, accounting, or financial advice.

4. Acceptable use

  • Do not use the demo to break the law, commit fraud, or interfere with PayPal services.
  • Do not attempt to bypass credentials, rate limits, or webhook verification.
  • Do not use another person's PayPal account or customer data without permission.
  • Do not enter passwords, payment card data, government identifiers, or other sensitive personal data.

5. Security and availability

The application supports an optional API key for direct API access and security headers for browser responses. Public deployments still need an authentication layer, a real webhook ID, restricted origins, and monitoring. No system is guaranteed to be secure.

The demo is provided as-is and as-available. There is no service level agreement, uptime commitment, backup, or support guarantee.

6. Limitation of liability

To the extent allowed by law, the maintainers are not liable for losses caused by use of the demo, model output, sandbox actions, service interruptions, or data loss. You use the demo at your own risk.

7. Changes

8. Contact
